# 小马 App 图标

桌面 App 图标源文件是 `assets/pony-icon.svg`，背景为纯色 `#e5ce4d`。
造型为瘦脸、歪嘴露齿笑的中性全身小马，脖后无鬃毛，马蹄采用同色直筒圆头轮廓。

应用直接使用已生成的 PNG 图标资源：

- `icon.png`：1024 × 1024，不透明的完整 App 图标。
- `favicon.png`：64 × 64，供 Web 使用。
- `adaptive-icon.png`：1024 × 1024，透明前景及安全边距；Android 背景由 app.json 设置为 #e5ce4d。
- `icon-hd-v2.png`：2048 × 2048 的小马高清版本。

App 内页面页头、取景器页头、相机导航、按钮和照片标签保持原来的相机图标。
